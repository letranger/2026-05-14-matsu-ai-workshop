# Step 4：換骨架 prompts

> **背景**：Step 3 已經產出 `小論文.docx`。此處示範「同一份內容、四種骨架」——
> 主軸是科學小論文，但同一套素材改個樣板就是研習心得、行政報告、教學設計、
> 科展報告。
>
> **現場 demo 哪一個**：建議選 **變體 A（研習心得）** demo 整套（教師最有感），
> 其餘三個變體用投影片秀出 prompt 與最終產出截圖即可。

---

## 變體 A｜研習心得（建議現場 demo）

```
我剛剛完成了一份《藍眼淚與環境生態》的科學小論文（已附上）。
請依以下要求，重寫成一份 800 字的「教師研習心得」：

【體裁】
- 第一人稱，口語化但保有專業度
- 段落分明，可分 4–5 段
- 開頭從「為什麼選這個主題」切入，避免流水帳

【內容重點】
1. 為什麼選擇藍眼淚作為跨域教學主題（在地連結、跨科能力、課綱對接）
2. 走完一輪 NotebookLM → Napkin → Claude 流程後，最有感的環節
3. 對課堂教學的啟發（具體可實施的兩個點子）
4. 一句帶到的反思：AI 在備課流程中是工具，而不是主導

【格式】
- Word 排版（標楷體 14pt）
- 不需要圖表
- 結尾不要寫「以上是我的心得」這類老套結語

請輸出 .docx
```

## 變體 B｜學校行政報告（公文／業務報告風格）

```
請把這份《藍眼淚與環境生態》小論文，改寫為「○○高中辦理跨域教學
研究專案成果報告」，依下列公文／業務報告格式：

【段落】
壹、主旨
貳、依據
參、辦理情形
  一、研究主題與緣起
  二、研究方法與工具運用（NotebookLM、Napkin、Claude）
  三、研究發現摘要
肆、效益分析
  一、學生面：跨域素養、研究方法
  二、教師面：備課流程、AI 輔助
  三、學校面：在地特色課程
伍、檢討與建議
  一、優點
  二、限制與後續改進
  三、預算建議（若需採購工具或進行延伸活動）
陸、附件
  附件 1：研究筆記摘要
  附件 2：因果圖、時間軸（嵌入）

【體裁】
- 公文體，第三人稱、客觀陳述
- 數字、條列、層次清楚
- 篇幅 1,500–2,000 字

請輸出 .docx
```

## 變體 C｜跨域教學設計（一頁式）

```
請把這份《藍眼淚與環境生態》小論文，轉為一份「跨域教學設計」一頁式
教案，可在課堂使用：

【欄位】
一、課程基本資料
  - 主題、適用年級、節數、跨域科目（生物 × 公民 × 國文）

二、學習目標（依 108 課綱核心素養撰寫）
  - 知識面：學生能說明...
  - 能力面：學生能分析...
  - 態度面：學生能反思...

三、教學流程（節節分明）
  第一節｜引起動機 + 文本閱讀
  第二節｜資料蒐集（學生模擬 NotebookLM 流程）
  第三節｜小組討論：兩派觀點對照
  第四節｜小論文撰寫指引

四、評量方式
  - 形成性：小組討論記錄
  - 總結性：小論文（評量規準附後）

五、教學資源
  - 列出今晚 NotebookLM 那 5 份素材的網址

六、評量規準（rubric）
  - 三向度（內容深度、論證品質、引註規範）× 三等第（優／良／可）

【格式】
- 表格化、條列化，避免長段文字
- 一頁能印完（A4 雙面亦可）
- 含一張嵌入圖（用論文裡的因果圖）

請輸出 .docx
```

## 變體 D｜科展報告（教育部中小學科展標準格式）

```
請把這份《藍眼淚與環境生態》小論文，擴寫為符合「中華民國中小學科學
展覽會」格式的研究報告，依下列章節：

【章節】
壹、研究動機
貳、研究目的
參、研究設備及器材
肆、研究過程或方法
伍、研究結果
陸、討論
柒、結論
捌、參考資料及其他

【特別要求】
- 第肆節「研究方法」要寫得具體可重現（步驟、工具、資料來源）
- 第伍節「研究結果」要有圖表，嵌入兩張 Napkin 圖
- 第陸節「討論」是評審最重視的部分，要清楚論證為什麼結果支持／不支持你的假設
- 全文 3,000–5,000 字

【格式】
- 標楷體、A4、固定行高
- 圖表編號（圖 1、圖 2、表 1...）
- 參考資料用 APA 格式

請輸出 .docx
```

## 共用提示（給 Claude 的後設說明，可放在每個 prompt 之前）

```
請以這份《藍眼淚與環境生態》小論文為唯一資料來源——
- 不要新增論文裡沒有的事實主張或數據
- 可以調整語氣、結構、詳略
- 可以重新組織段落順序
- 引註與參考資料必須沿用論文中的來源
```

## 收尾講法（口頭帶過）

> 「你看到的是同一份核心內容，但骨架可以是論文、心得、報告、教案、
> 科展。回家你要寫研習心得？同一招。要交活動報告？同一招。學生交
> 完小論文要你寫評語表？同一招。
>
> 主軸是小論文，但*流程才是禮物*。」
