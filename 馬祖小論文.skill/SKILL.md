# 馬祖小論文流程

這是一個四步式跨工具工作流，把分散的素材變成成品文件。設計給高中教師、行政人員、或高中生使用。

## 觸發方式

當使用者說：
- 「請用馬祖小論文流程，幫我寫『〔主題〕』」
- 「我想用『藍眼淚小論文』那套流程做一份『〔主題〕』」
- 「跑馬祖小論文 SOP，主題是〔X〕」

請依下列四步執行。

## 必備輸入

執行前向使用者確認：
1. **主題**：要研究的題目（必填）
2. **目標格式**：小論文／研習心得／行政報告／教學設計／科展報告（預設小論文）
3. **素材來源**：學員上傳的 PDF／網址清單（至少 3 份，建議 5–8 份）
4. **目標讀者**：高中生／教師／長官／審查委員／一般大眾（影響語氣）
5. **字數要求**：預設 2,000–3,500 字（小論文）

## 四步流程

### Step 1｜讀（NotebookLM）

> 此步在 NotebookLM 介面完成；本 Skill 假設使用者已產出 `研究筆記.docx`。

請依序問四個遞進問題：

```
Q1（大方向）  〔主題〕是什麼？相關背景？
Q2（細節）    具體機制／成因／構成要素？
Q3（觀點對照）不同立場／資料來源觀點的差異？
Q4（教學切入）學生小論文最值得做的研究問題是什麼？
```

最後一步：

```
Q5（整理）請把上述四題回答打包成「研究筆記」，含：
- 完整參考文獻（編號）
- Napkin 用條列：（一）因果圖 5–6 條；（二）時間軸 5–7 個節點
```

人工把關（這一步老師價值最高）：
- 讀一遍刪錯的
- 核對出處編號
- 砍重複（順便省 token）
- 補旁註（教學判斷）

### Step 2｜畫（Napkin × 2）

從研究筆記第七節（Napkin 用條列）複製貼上到 Napkin，依下列產出兩張圖：

- **圖 1｜成因／結構因果圖**：5–6 條主要因素，分類分組
- **圖 2｜歷史／研究時間軸**：5–7 個關鍵節點

每張各挑一個視覺風格，輸出 PNG。

### Step 3｜寫（Claude 第一次）

上傳：
- `研究筆記.docx`
- `圖 1.png`、`圖 2.png`
- `小論文範本.md`（或本 Skill 同層的範本檔）

請 Claude 同時做四件事：
1. 讀範本，抽結構（章節順序、字數比例、引註格式）
2. 從研究筆記寫每一節
3. 把兩張圖嵌入「研究結果」段落對應位置
4. 整篇排版輸出 `.docx`

### Step 4｜變（Claude 第二次）

上傳上一步的 `小論文.docx`，依需求換骨架（見 `換骨架-prompts.md`）：

| 變體 | 骨架                              | 適用情境                      |
|------|-----------------------------------|-------------------------------|
| A    | 研習心得（800 字、第一人稱）      | 教師完成研習、學生反思        |
| B    | 行政報告（公文體：主旨／依據／辦理情形…）| 學校送長官、計畫成果          |
| C    | 跨域教學設計（一頁式含 rubric）   | 課程設計、教學實踐            |
| D    | 科展報告（中小學科展標準格式）    | 學生科展、研究計畫送審        |

**核心原則**：
- 內容只生成一次，骨架可以隨需求換
- 不要新增論文裡沒有的事實主張或數據
- 引註與參考資料必須沿用論文中的來源

## 撞牆 fallback（四層）

| 層 | 動作                  | 適用情境                          |
|----|-----------------------|-----------------------------------|
| 1  | 切到 Haiku 4.5        | 出現 Get Pro／load 失敗，最常奏效 |
| 2  | 開新對話              | input token 累積過多              |
| 3  | 退到 Gemini 免費      | 容量更寬，prompt 完全相容         |
| 4  | 退到複製貼上          | 比 fetch 省 token                 |

## 模型建議

- Step 3（多附件、嚴格範本）→ **Sonnet 4.6**
- Step 4（單純改寫）→ **Haiku 4.5**
- 主題很複雜、需要深度分析 → **Opus 4.7**

## 不該丟雲端的內容

- 學生作文・輔導紀錄・IEP・未公開競賽作品・段考考卷
- 判準：**「這段如果被截圖貼到網路上，我會崩潰嗎？」**
- 進階解法：本機 AI（Ollama + Llama / Gemma）跑筆電上
